name: przeglad-zasad
description: Przegląd pull requesta pod kątem zasad tego projektu (CLAUDE.md i .claude/rules/). Używaj przy przeglądzie PR, nie do oceny stylu.
---

Przejrzyj pull request tylko pod kątem zasad projektu.

1. Przeczytaj CLAUDE.md i pliki w `.claude/rules/`.
2. Obejrzyj zmiany: `gh pr diff <numer>`.
3. Zgłaszaj wyłącznie naruszenia, które możesz zacytować z zasad. Przy każdym podaj plik, cytat zasady i jedno zdanie, jak to poprawić.
4. Jeśli naruszeń nie ma, napisz jedno zdanie: „Zasady projektu: bez uwag.”

Nie oceniaj stylu ani pomysłu i niczego nie zmieniaj w kodzie.
